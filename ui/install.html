ARPANET SUITE // ANDROID

Instalação do aplicativo nativo sem emulador.

  1. Certifique-se de que o computador e o celular estão na mesma rede Wi-Fi.
  2. Toque no botão abaixo para abrir a Console do Arpanet.
  3. No Chrome, toque no menu (três pontos no topo).
  4. Toque em "Instalar aplicativo" ou "Adicionar à tela inicial".
